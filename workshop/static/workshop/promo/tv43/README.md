# Клиентский ТВ (55″) + реклама Full HD

## Как работает

1. `python app.py` поднимает Django и **агент клиентского экрана**.
2. В **Админ → Клиентский ТВ** нажмите «Сканировать мониторы», назначьте:
   - монитор **телевизора** (клиентская зона);
   - монитор **CRM** (что дублировать).
3. Выбор **сохраняется в БД** и восстанавливается после перезапуска.
4. В шапке CRM тумблер **ТВ: реклама / CRM**:
   - выкл (по умолчанию) — карусель рекламы на ТВ;
   - вкл — дубль выбранного монитора CRM на ТВ.

`slide-01.png` … `slide-08.png`, `bg-three-windows-fhd.png`, страница `/tv`.

## Заметки

- Рабочий стол Windows остаётся **расширенным** (2 монитора + ТВ), без системного «Дублировать все».
- Агент открывает Chrome/Edge на координатах ТВ (`--app=http://127.0.0.1:8000/tv`).
- Отключить агент: `IT_MASTER_CLIENT_DISPLAY=0` или тумблер «Агент включён» в админке.
