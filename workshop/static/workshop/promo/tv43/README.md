# ИТ-М — реклама на ТВ (Full HD)

Два способа показа. Выбор в **Админ-панель → ТВ-реклама**.

## По URL (Smart TV / Android-приставка)

ПК и телевизор в одной Wi-Fi сети. На ТВ откройте браузер и вставьте ссылку `/tv`.

Это **упрощённая** страница: фон через `<img>` на весь экран (`object-fit: contain`),
без canvas-пыли, без затемнения и без CSS-обрезки. Так Яндекс-браузер на приставке
показывает витражи целиком.

Пример: `http://192.168.1.10:8000/tv`

Полная «киношная» версия (если нужна на ПК): `/tv?full=1`

## По HDMI (монитор этого ПК)

«Найти мониторы» → выбрать ТВ → «Открыть на весь экран».

- CRM запускает **отдельный** Chrome/Edge (`runtime/tv-chrome-profile`, `--kiosk`).
- Окно позиционируется по координатам монитора из ОС (`EnumDisplayMonitors`).
- Окно CRM **не** переносится и не закрывается.
- **Esc** на ТВ закрывает только окно рекламы (`POST /tv/close` + `window.close`).
