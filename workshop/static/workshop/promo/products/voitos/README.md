# Voitos — promo

Материалы для презентации продукта (в т.ч. встреча с трактористами).

## Файлы

| Файл | Назначение |
|------|------------|
| `index.html` | Стартовая страница со ссылками |
| `presentation-traktoristy.html` | Слайды: проект + работа тракториста / водителя |
| `demo-sosedi.html` | Демо-лендинг «для нашего двора» (TV / экран) |
| `voitos-mark.png` | Логотип |
| `qr-latest-apk.png` | QR на последний APK |

## Как показывать

1. Откройте `index.html` или сразу нужный файл в Chrome / Edge.
2. **Презентация трактористам:** `presentation-traktoristy.html`  
   - ← → или пробел — слайды  
   - F11 — полный экран  
   - Печать в PDF: Ctrl+P → «Сохранить как PDF» (все слайды)
3. **Демо для соседей:** `demo-sosedi.html` — листайте вниз колесом / пультом.

Раздавайте всю папку `promo/` целиком — картинки лежат рядом с HTML.
